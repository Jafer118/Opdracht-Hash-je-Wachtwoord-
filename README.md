# Secure Login and Registration System (Password Hashing)

## Project Overview
This project is a secure command-line login and registration system written in **PHP**. It is designed to demonstrate secure user authentication, password hashing, input validation, and robust error management using `try-catch` blocks.

## How to Run the Script
1. Ensure you have **PHP** installed on your local machine (with CLI support).
2. Open your terminal or command prompt.
3. Run the script using the following command:
   ```bash
   php script.php
